# Project 2: Network Diagnostics Pro 🌐

A native Android network telemetry and latency inspection tool built with **100% Java**, **Modern XML Layouts**, and **Clean MVVM Architecture**.

## Features
- **Real-Time Interface Telemetry**: Wi-Fi vs Cellular transport detection, link speed (Mbps), and local IPv4 resolution.
- **Multi-Server Socket & Ping Engine**: Multi-threaded latency calculation against major DNS and web gateways (Google, Cloudflare, OpenDNS).
- **MVVM Pattern**: Powered by Android Architecture Components (ViewModel, LiveData, ViewBinding).
- **Responsive Material 3 UI**: Card layouts, color-coded latency indicators, and smooth nested scrolling.
